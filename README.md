## Project Overview

## Repo Structure

### Electrical

Contains a KiCad project for initial wiring schematics, component datasheets, and component selection information. 

### Mechanical

Contains CAD files for the radio casing. These files were besed off .stl files downloaded from [@RainyCobra_1262395 on Printables](https://www.printables.com/@RainyCobra_1262395). Huge credit to their hard work! Solidworks files have been created using the measurements of these stls and will be altered as required to accomodate mounting/positioning of electrical components. 

### Software

Contains all project code.
